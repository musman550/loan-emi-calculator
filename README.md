# Loan EMI Calculator

Work out your monthly loan payment, total interest and year-by-year balance, and see how an extra monthly payment shortens the loan.

**Use it online (free, no signup):** https://musman550.github.io/loan-emi-calculator/

## Why use it
- Runs completely in your browser: what you type is never uploaded or stored.
- Free, open source (MIT) and without limits or accounts.
- Works on phones and desktops.

## Run it yourself
Download `index.html` from this repository and open it in a browser. Nothing else is needed.
